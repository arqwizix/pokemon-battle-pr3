# ПР 3_5 — Модулі. Класи

Покемон-бій на JavaScript з модулями ES6 та класом `Pokemon`, який створює
героя (Pikachu) і противника (Charmander).

Файли:
- `pokemon.js` — клас `Pokemon`, стан HP та його відображення;
- `main.js` — логіка бою, кнопки та створення персонажів;
- `utils.js` — випадкове число;
- `battle-log.js` та `logs.js` — українські повідомлення про удари;
- `click-counter.js` — замикання зі станом лічильників;
- `index.html`, `style.css`, `assets/` — інтерфейс гри.

## Запуск

Оскільки проєкт використовує `type="module"`, відкривати `index.html`
подвійним кліком через `file://` не слід. Запустіть локальний вебсервер у папці
проєкту:

```bash
python -m http.server 8000
```

Відкрийте http://localhost:8000 у браузері. Або скористайтеся розширенням
**Live Server** у VS Code.

Кожна з двох атак має обмеження в 7 натискань. Кнопка «Нова гра» без ліміту —
вона відновлює HP, лічильники та очищує журнал бою.
